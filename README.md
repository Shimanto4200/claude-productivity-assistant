# Personal Productivity Assistant (Claude Projects & Skills)

A personal productivity assistant built with Claude Projects & Skills.

It helps plan the day around real tasks — replying to client emails, preparing
proposals, attending meetings, updating profiles and learning — using the
project's knowledge and skills instead of generic advice.

## Files

- `sample-tasks.md` — the sample task list used to demo the assistant

This repo documents the assistant's setup and demo data; there is no workflow
JSON for this one because it runs on Claude Projects & Skills, not n8n/Make.
